## Special Project Spotlight: Multi-KOL Narrative Agent

Build an agent that monitors up to 20 user-selected crypto creators or market voices (KOLs) on X, with optional Discord or Telegram sources. It should:

- identify mentioned tokens, sentiment, conviction and urgency
- detect when trusted voices converge on the same narrative
- create a practice position using transparent signal rules and user-defined risk limits
